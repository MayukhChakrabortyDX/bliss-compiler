# Types

The Bliss type system is still evolving. This page is a placeholder for the formal type model as the compiler stabilizes.

## Goals

The type system is expected to participate directly in Bliss's approach to memory safety and systems programming.

## Current status

No stable public type specification has been finalized yet. Treat examples in this section as design notes rather than a frozen language contract.

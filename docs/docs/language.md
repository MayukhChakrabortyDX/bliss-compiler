# The Bliss Language

Bliss is a systems programming language exploring a new outlook on memory safety, programming paradigms, and the fundamentals of systems software.

## First principles

Bliss is being designed from first principles. The language is intentionally willing to question conventions that are usually treated as fixed boundaries.

## A small program

```bliss
fx main() {
    // Your Bliss program starts here.
}
```

## Where to go next

The language documentation will grow alongside the compiler. Start with the syntax, then move into the type and memory model.

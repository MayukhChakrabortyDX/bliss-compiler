# Memory

Memory safety is one of the central areas being reconsidered in Bliss.

## A systems-language problem

Bliss aims to preserve the control expected from systems programming while exploring a different model for expressing safe memory usage.

## Design status

The memory model is experimental. This section will become the authoritative specification as the design settles.
